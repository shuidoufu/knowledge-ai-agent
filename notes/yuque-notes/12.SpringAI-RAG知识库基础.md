:::color4
RAG（Retr⁠ieval-Augmented ‌Generation，检索增强生成）是一种**<font style="color:#DF2A3F;">结合信息检索技术和 A‎I 内容生成</font>**的混合架构，可以解决‌大模型的**<font style="color:#DF2A3F;">知识时效性限制和幻觉</font>**问题。

:::

:::color4
所有的 RAG ，都是基于 Advisors 拦截器实现的，通过向 advisor 拦截器中传入知识库，从而向 AI 提问时，检索到相应的内容传给 AI，进行整理回复。



例如：

@Resource

private **<font style="color:#DF2A3F;">Advisor</font>** LoveAppAdvisor;



ChatResponse chatResponse = chatClient  
    .prompt()  
    .user(message)  
    .advisors(spec -> spec.param(CHAT_MEMORY_CONVERSATION_ID_KEY, chatId)  
              .param(CHAT_MEMORY_RETRIEVE_SIZE_KEY, 10))  
**<font style="color:#DF2A3F;">    // 基于云知识库问答  
</font>****<font style="color:#DF2A3F;">    .advisors(LoveAppAdvisor)</font>**  
    .call()  
    .chatResponse();

由于我们配置了 Configuration 配置类，因此 spring 在加载Advisor 类的时候，会自动调用我们配置的相应的 RAG 检索的配置类，从而进行装配。

:::

## 一、RAG 工作流程、概念
:::color4
核心步骤：

1. 文档收集和切割
2. 向量转换和存储
3. 文档过滤和检索
4. 查询增强和关联

:::

### 文档收集和切割
文档收集：从各种来源（网页、PDF、数据库等）收集原始文档

文档预处理：清洗、标准化文本格式

文档切割：⁠将长文档分割成适当‌大小的片段（俗称 chunks）

1. 基于固定大小（如 512 个 token）
2. 基于语义边界（如段落、章节）
3. 基于递归分割策略（如递归字符 n-gram 切割）

## 二、Spring AI + 本地知识库
### 引入依赖
```xml
<!--   markdown文档加载器     -->
<dependency>
	<groupId>org.springframework.ai</groupId>
	<artifactId>spring-ai-markdown-document-reader</artifactId>
	<version>1.0.0-M6</version>
</dependency>
```

### 创建文档加载器类
```java
@Slf4j
@Component
public class LoveAppDocumentLoader {
	private final ResourcePatternResolver resourcePatternResolver;

	LoveAppDocumentLoader(ResourcePatternResolver resourcePatternResolver) {
		this.resourcePatternResolver = resourcePatternResolver;
	}

	//  加载多篇MD文档 
	public List<Document> loadMarkdowns() {
		List<Document> allDocuments = new ArrayList<>();
		try {
			// '*' 通配符
			Resource[] resources = resourcePatternResolver.getResources("classpath:document/*.md");
			for (Resource resource : resources) {
				// 每篇文档的配置
				String fileName = resource.getFilename();
				// markdown会自动切分
				MarkdownDocumentReaderConfig config = MarkdownDocumentReaderConfig.builder()
				.withHorizontalRuleCreateDocument(true)
				.withIncludeCodeBlock(false)
				.withIncludeBlockquote(false)
				.withAdditionalMetadata("filename", fileName)
				.build();
				MarkdownDocumentReader reader = new MarkdownDocumentReader(resource, config);
				// 把所有文档的加载器放到list中，方便后续调用多篇文档进行检索
				allDocuments.addAll(reader.get());
			}
		} catch (IOException e) {
			log.error("Markdown 文档加载失败", e);
		}
		return allDocuments;
	}
}
```

### 将文档放入向量数据库
```java
/**
 * 恋爱大师向量数据库配置(初始化基于内存的向量数据库Bean)
 */
@Configuration
public class LoveAppVectorStoreConfig{

    @Resource
    private LoveAppDocumentLoader loveAppDocumentLoader;

    @Bean
    public VectorStore loveAppVectorStore(EmbeddingModel embeddingModel) {
        SimpleVectorStore simpleVectorStore = SimpleVectorStore.builder(embeddingModel).build();
        simpleVectorStore.add(loveAppDocumentLoader.loadMarkdowns());
        return simpleVectorStore;
    }

}
```

### 新建 chat 会话，实现 RAG 知识库问答
```java
// AI 恋爱知识库问答功能
@Resource
private VectorStore loveAppVectorStore;

/**
 * 用 RAG 向量知识库进行对话
 * @param message
 * @param chatId
 * @return
 */
public String doChatWithRag(String message, String chatId){
	ChatResponse chatResponse = chatClient
	.prompt()
	.user(message)
	.advisors(spec -> spec.param(CHAT_MEMORY_CONVERSATION_ID_KEY, chatId)
			  .param(CHAT_MEMORY_RETRIEVE_SIZE_KEY, 10))
	// 应用 RAG 知识库问答
	.advisors(new QuestionAnswerAdvisor(loveAppVectorStore))
	.call()
	.chatResponse();
	String content = chatResponse.getResult().getOutput().getText();
	log.info("content: {}", content);
	return content;
}
```

## 三、Spring AI + 云知识库服务
### 准备云知识库
### 创建基于云知识库的文档检索器类
```java
/**
 * 自定义基于阿里云知识库服务的 RAG 增强顾问
 */
@Configuration
@Slf4j
public class LoveAppRagCloudAdvisorConfig {

    @Value("${spring.ai.dashscope.api-key}")
    private String dashScopeApiKey;

    @Bean
    public Advisor loveAppRagCloudAdvisor() {
        DashScopeApi dashScopeApi = new DashScopeApi(dashScopeApiKey);
		// 知识库索引名称
        final String KNOWLEDGE_INDEX = "恋爱大师";
        DocumentRetriever dashScopeDocumentRetriever = new DashScopeDocumentRetriever(dashScopeApi,
                DashScopeDocumentRetrieverOptions.builder()
						// 你的知识库名称
                        .withIndexName(KNOWLEDGE_INDEX)
                        .build());
        return RetrievalAugmentationAdvisor.builder()
                .documentRetriever(dashScopeDocumentRetriever)
                .build();
    }
}
```
